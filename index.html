Selected Features for Neural Network Modeling

The following features were selected based on exploratory analysis, domain understanding, and correlation relevance. Variables marked as leakage or optional are excluded from the predictive model.

Exports the current feature-engineered dataset used across the dashboard.
Feature Type Description Use in Model
rank_diffNumericRank₂ − Rank₁✅ Yes
pts_diffNumericPts₁ − Pts₂✅ Yes
odd_diffNumericOdd₂ − Odd₁ (lower odds ⇒ higher chance)✅ Yes
h2h_advantageNumeric+1 if Player₁ leads H2H, −1 if Player₂✅ Yes
last_winnerNumeric+1 if Player₁ won last mutual match✅ Yes
surface_winrate_advNumericSurface-specific winrate difference✅ Yes
yearNumericMatch year (trend control)✅ Yes
SurfaceCategoricalSurface type (hard/clay/grass)✅ Encoded
CourtCategoricalIndoor / Outdoor✅ Encoded
RoundCategoricalTournament round (R32, QF, SF, F)✅ Encoded
recent_win_rate_5 DerivedNumericShort-horizon rolling win rate over the last 5 matches✅ Yes
recent_win_rate_10 DerivedNumericRolling win rate over the last 10 matches (aligned with correlation analysis)✅ Yes
rolling_win_rate_10 DerivedNumericLegacy alias for 10-match rolling form used elsewhere in the dashboard⚙️ Optional
streak_value DerivedNumericSigned counter of consecutive wins (+) or losses (−) shared with the streak timeline✅ Yes
fatigue_7d DerivedNumericMatches played in the previous 7 days (player load)✅ Yes
fatigue_14d DerivedNumericMatches played in the previous 14 days✅ Yes
fatigue_30d DerivedNumericMatches played in the previous 30 days✅ Yes
surface_trend DerivedNumericShort-term (5-match) minus long-term (15-match) win rate for Player₁ on the current surface✅ Yes
Player_1 / Player_2TextPlayer names (used for H2H only)❌ No
WinnerTextMatch winner (reveals target)❌ Leakage
ScoreTextFinal score (reveals outcome)❌ Leakage
TournamentCategoricalTournament name (many unique values)⚙️ Optional

Feature selection focuses on interpretable, predictive, and non-leaking variables suitable for Neural Network classification of match outcomes.
